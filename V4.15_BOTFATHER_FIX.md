# Zento v4.15 — BotFather command fix

- Added a built-in system account `@BotFather`.
- `/start`, `/help`, `/newbot`, `/mybots`, `/cancel`, `/setname`, and `/setdescription` are handled inside the BotFather chat.
- `/newbot` now uses a two-step flow: bot name, then a unique username ending in `bot`.
- A secure Zento Bot API token is generated and stored server-side.
- User commands are stored normally and BotFather replies are delivered in real time through Socket.IO.
- Added persistent `botfather_sessions` schema.
- The BotFather account is created automatically at backend startup if it does not already exist.

The implementation is Telegram-inspired and compatible with Zento's existing Bot API; it is not connected to Telegram's infrastructure.
