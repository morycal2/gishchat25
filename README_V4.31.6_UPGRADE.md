# Zento v4.31.6

- Persistent moderation state survives refresh/re-login.
- Banned users are blocked server-side from messaging, calls and conferences.
- Incoming calls to restricted users are rejected and the caller is notified.
- Added persistent site-wide and per-section service controls in the creator panel.
- Added persistent announcements with create/edit/activate/deactivate/delete.
- Added user-facing announcements panel.
- Added server-side feature gates for messages, calls, stories, bots, support, groups and channels.
- Kept the custom Zento dialog system; no native browser prompt/confirm UI is used for the new management flows.
