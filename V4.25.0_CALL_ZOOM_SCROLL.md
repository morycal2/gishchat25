# Zento v4.25.0 — Call Zoom & Scroll

- Outgoing caller UI never shows Answer/Reject controls.
- Video call screen is vertically scrollable.
- Private video call remote/local participant zoom toggles.
- Conference participant tiles have large zoom buttons; clicking again restores the grid.
- Conference grid supports scrolling when many participants are present.
- Zoomed participant uses a larger single-row tile while preserving controls.
