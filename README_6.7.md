# Zento 6.7 — Advanced Media Editor

این نسخه روی پایه‌ی v6.6 ساخته شده و ادیتور رسانه را پیشرفته‌تر می‌کند:

- عکس: برش آزاد و نسبت‌های 1:1، 4:3 و 16:9
- عکس: فیلترهای زنده، چرخش، متن روی عکس و نقاشی با قلم
- ویدیو: انتخاب زمان شروع و پایان و پیش‌نمایش بخش انتخابی
- ویدیو: انتخاب فریم کاور و نمایش آن به‌عنوان poster پیام
- کپشن برای عکس، ویدیو، آهنگ و سایر رسانه‌ها قبل از ارسال
- نمایش درصد آپلود
- ذخیره‌ی مشخصات ویرایش رسانه در `messages.media_meta`
- سازگار با PostgreSQL/Supabase موجود

در زمان استقرار، سرور به‌صورت خودکار ستون `media_meta` را با `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` اضافه می‌کند.

نکته: برش و فیلتر عکس در مرورگر پردازش می‌شوند. برش ویدیو در مرورگر با `MediaRecorder` انجام می‌شود؛ اگر مرورگر امکان `captureStream` نداشته باشد، فایل اصلی بدون برش ارسال می‌شود.
