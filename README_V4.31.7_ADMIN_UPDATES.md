# Zento v4.31.7 — Admin & Account Update

این نسخه شامل:
- مخفی شدن عکس پروفایل کاربران در جدول مدیریت کاربران
- مدیریت پیشرفته کاربران: حذف حساب، مسدود/آزاد کردن ورود، نمایش مدت غیرفعال بودن
- گفتگوی پشتیبانی لحظه‌ای با Socket.IO برای کاربر و ادمین
- مدیریت حساب کاربر: تغییر رمز، درخواست تغییر ایمیل با تأیید ادمین و پیام «حداکثر ۲ روز»، حذف حساب
- بخش تأیید تغییر ایمیل در پنل سازنده
- اعلان لحظه‌ای اطلاعیه‌های جدید و نشان نارنجی روی زنگوله
- بخش‌های مستقل گروه‌ها و کانال‌ها در پنل مدیریت
- حذف مدیریتی گروه/کانال توسط سازنده
- ثبت آخرین فعالیت کاربر در ورود و اتصال Socket

بعد از Deploy، migrationها به‌صورت خودکار در `ensureAdminSchema()` اجرا می‌شوند.
