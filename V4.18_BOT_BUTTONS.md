# Zento v4.18 — Bot Buttons & Keyboard Upgrade

- Professional bot button builder in the Bot Manager.
- Supports inline/glass buttons below bot messages.
- Supports persistent-style reply keyboard buttons for the chat composer area.
- URL buttons open safe HTTPS/HTTP destinations.
- Callback buttons create `callback_query` updates for polling/webhooks.
- Bot API `sendMessage` accepts `reply_markup` with `inline_keyboard` or `keyboard`.
- Bot API includes `answerCallbackQuery`.
- Configured commands can automatically answer users with their saved response and keyboard.
- Bot API messages are emitted over Socket.IO immediately, so chats update live.
- `reply_markup` is persisted on messages.

## Example

```json
{
  "chat_id": 123,
  "text": "یکی را انتخاب کن:",
  "reply_markup": {
    "inline_keyboard": [[
      {"text":"وب‌سایت","url":"https://example.com"},
      {"text":"خرید","callback_data":"buy"}
    ]]
  }
}
```

Keep bot tokens private.
