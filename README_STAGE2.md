# Zento v7.1 — Stage 2

Stage 2 واقعی روی پروژه Stage 1:
- پیام‌های ناپدیدشونده: 10s / 1m / 1h / 1d / off
- حذف خودکار پیام‌های منقضی‌شده از دیتابیس + Socket event
- لینک مستقیم پیام `#/msg/<conversationId>/<messageId>` و highlight پیام
- کپی لینک از منوی هر پیام
- جستجوی داخل گفتگو بر اساس متن، فرستنده، تاریخ و نوع رسانه
- فیلتر عکس، ویدیو، صوت، فایل و لینک
- read receipt و صفر شدن unread با باز کردن گفتگو
- نمایش ✓ و ✓✓ خوانده‌شده
- انتخاب چند پیام و ارسال به‌عنوان quote bundle
- forward پیام به گفتگو با API
- unread count در لیست گفتگوها

استفاده:
- روی `جستجو` بالای چت بزن: جستجوی پیشرفته باز می‌شود.
- روی پیام: «🔗 لینک» برای لینک مستقیم، «☑ انتخاب» برای انتخاب چند پیام، «↪ فوروارد» برای فوروارد.
- از `بیشتر` چت، گزینه 1 برای پیام‌های ناپدیدشونده.

این نسخه دیتابیس را حذف یا reset نمی‌کند؛ migrationها در startup با IF NOT EXISTS/ADD COLUMN IF NOT EXISTS اجرا می‌شوند.
