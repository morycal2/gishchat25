# Zento v4.26.0 — Premium Call Center & Creator Control Center

- Premium redesigned voice/video call UI with identity, live status, timer and scrollable stage.
- Incoming calls show Answer/Reject; the caller never sees Answer/Reject.
- Answer/Reject disappear immediately after answering.
- Creator login: superadmin@zento.com with the configured creator password. Password verification uses scrypt and timing-safe comparison; credentials are not exposed to the browser.
- Superadmin control center with overview statistics, users, conversations, calls and support requests.
- Creator credentials can be overridden safely with SUPERADMIN_EMAIL, SUPERADMIN_PASSWORD_SALT and SUPERADMIN_PASSWORD_HASH environment variables.
