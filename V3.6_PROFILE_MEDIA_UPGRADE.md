# Zento v3.6 – Inline Audio, Folder Add-Chat, Profile Media

- Voice/music now use a custom inline player inside the message bubble instead of a full-screen player.
- Folder UI adds an “افزودن گفتگو” action for user-created folders.
- Profiles support up to 10 profile gallery photos and 2 profile songs.
- Added profile media API and database table.
- Public user profiles expose profile photos and songs.
