# Zento v4.32 Professional Upgrade

## Added
- Professional Center UI
- Message edit API with edit timestamp and ownership/time checks
- Message pin/unpin and pinned-message list
- Poll creation, voting and results APIs
- Per-conversation drafts
- Scheduled messages with background worker
- Invite links with expiry/use limits and join endpoint
- Conversation mute API
- Favorite contacts API
- Conversation moderation rules: anti-link, anti-spam, slow mode
- Conversation admin action log API
- Device/session records with revocation
- TOTP 2FA setup/enable/disable and recovery codes
- Professional CSS/UI cards
- Database migration is idempotent and runs automatically on startup

## Security notes
- Existing legacy JWTs without a session id remain accepted for compatibility. Newly issued normal-user JWTs receive a session id and can be revoked.
- 2FA setup uses standard TOTP compatible with authenticator apps.
- Full end-to-end encryption is intentionally not claimed in this upgrade because implementing it correctly requires client-side key management, identity verification, encrypted payloads, backup/recovery design, and migration of existing plaintext messages.
- Storage privacy should still be migrated from public objects to signed URLs before treating private media as end-to-end/private content.
