# Zento v4.16 — Bot Platform Upgrade

- Fixed BotFather-created usernames opening as “user not found” by giving every bot a real Zento user account.
- Added bot profile management: name, description, avatar and webhook URL.
- Added BotFather `/setphoto`, `/settings` and improved `/mybots` guidance.
- Added Telegram-inspired online Bot API endpoints: `getMe`, `sendMessage`, `getUpdates`, `setWebhook`, `getWebhookInfo`, `deleteWebhook`.
- Added persistent bot update queue for polling and webhook delivery.
- Bot API messages are sent from the bot account instead of the owner's personal account.
- Added per-bot command management UI and API documentation in the Zento bot manager.
