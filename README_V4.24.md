# Zento v4.24.0

## این نسخه
- تماس حرفه‌ای: نمایش نام/پروفایل، تایمر بعد از پاسخ، پایان خودکار تماس بدون پاسخ بعد از ۶۰ ثانیه.
- ثبت تاریخچه تماس در PostgreSQL: تاریخ، ساعت، ورودی/خروجی، وضعیت و مدت مکالمه برحسب ثانیه.
- بایگانی پیشرفته: جستجو و منوی شناور راست‌کلیک روی چت برای بیرون آوردن از بایگانی.
- سرعت بالاتر: لیست گفتگوها با query تجمیعی و بدون درخواست settings جداگانه برای هر چت؛ پیام‌ها با batch lookup کاربران/پروفایل‌ها/ربات‌ها و حداکثر ۱۵۰ پیام اخیر.
- مدیریت پیشرفته‌تر گروه/کانال: رسانه، پیش‌نمایش لینک، عضویت با لینک و ضداسپم علاوه بر مجوزهای قبلی.
- پروفایل کاربری با نمایش آمار گالری/آهنگ/استوری و وضعیت فعال.
