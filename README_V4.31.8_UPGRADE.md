# Zento v4.31.8

- تیک آبی برای کاربران، ربات‌ها، گروه‌ها و کانال‌ها با مدیریت سازنده
- تیک آبی خودکار برای حساب‌های مدیریتی، BotFather و حساب اطلاع‌رسانی
- تبدیل پیام صوتی به متن با مسیر امن سرور و `OPENAI_API_KEY`
- رفع کلیک اطلاعیه‌های کاربران و نشان خوانده‌نشده
- حساب‌های رسمی با امکان تغییر عکس توسط سازنده
- پنل مدیریت با بخش‌های خانه، بازی، پیامرسان، زینو، ویترین و فیلم
- همه ابزارهای فعلی مدیریت پیام‌رسان زیر بخش پیامرسان باقی مانده‌اند
- تغییر نسخه فرانت‌اند برای جلوگیری از کش شدن `app.js`

برای تبدیل ویس به متن، روی سرور Railway متغیر `OPENAI_API_KEY` را تنظیم کنید. مدل پیش‌فرض `gpt-4o-mini-transcribe` است و با `OPENAI_TRANSCRIBE_MODEL` قابل تغییر است.
