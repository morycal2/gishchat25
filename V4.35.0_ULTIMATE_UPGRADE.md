# Zento v4.35.0 Ultimate

- E2EE key rotation API and client helper
- device/key fingerprints for human verification
- encrypted attachment manifest API + client-side WebCrypto helper
- call security fingerprints
- PostgreSQL notification queue worker with retry/backoff
- Enterprise health reports v4.35 feature set
- package version 4.35.0

## Important
The encrypted attachment helper encrypts bytes in the browser; actual upload/storage integration must send the resulting ciphertext bytes to the media service. Call security fingerprints verify exchanged public keys but do not replace a complete SRTP/DTLS WebRTC implementation.
