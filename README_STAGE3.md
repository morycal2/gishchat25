# Zento v7.4 — Stage 3

Stage 3 امکانات واقعی زیر را به Stage 2 اضافه می‌کند:

- آمار کاربر: پیام‌ها، گروه‌ها، کانال‌ها، رسانه‌ها، مخاطبین و عمر حساب
- Badgeهای خودکار: کاربر فعال، عضو قدیمی، سازنده گروه، تولیدکننده محتوا
- مدیریت حرفه‌ای گروه/کانال برای مالک و ادمین
- تنظیمات حالت کند، فقط ادمین‌ها، تأیید اعضای جدید، مخفی‌کردن اعضا و نظرها
- افزودن/حذف ادمین با سطح دسترسی
- اعلان هوشمند: تجمیع پیام‌های متوالی به جای اعلان تک‌به‌تک
- اعلان مرورگر در صورت اجازه کاربر
- رابط Stage 3 در منوی اصلی

Migration هنگام شروع سرور اجرا می‌شود.
