# Zento v4.19 — Advanced Bot Platform

- Added Telegram-style group/channel bot membership management from the Bot Manager.
- Bot owners can add/remove a bot from managed groups and channels.
- Added per-chat bot permissions: read, send, and admin/management.
- Added Bot API methods: getChat, getChatMember, leaveChat, getMyCommands, setMyCommands, deleteMyCommands.
- Added BotFather commands for token retrieval/revocation, command-menu management, About text, privacy mode, inline mode, group joining, and bot deletion.
- Bot privacy mode is respected for group messages: private mode receives commands/mentions; disabled mode receives all group messages.
- Existing glass/inline buttons, reply keyboards, webhooks and polling remain compatible.
