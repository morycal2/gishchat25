# Zento v4.24.0 — Calls, Archive, Performance & Management

- Call UI hides answer/reject controls after answering and starts the call timer only after connection.
- Caller/receiver name and profile photo are shown during calls.
- Calls are stored in PostgreSQL with status, date/time, answer/end timestamps and duration.
- Added in-app call history with date, direction, status and exact duration in seconds.
- Archive panel upgraded with search and a compact right-click menu for “بیرون آوردن از بایگانی”.
- Conversation list no longer performs one settings request per chat.
- Message loading reduced to the latest 150 messages and user/profile/bot data is batch-loaded.
- Group/channel management gained media, link preview, join-by-link and anti-spam controls.
- User profile presentation received richer stats/status treatment.
