# Zento v4.37.1 — Call / TURN Fix

- Removed dependency on the old hard-coded public Open Relay fallback.
- Added server-side Metered TURN credential fetching and short cache.
- Added support for `METERED_TURN_API_URL` + `METERED_TURN_API_KEY`.
- Kept optional direct TURN env vars.
- Increased ICE gathering wait from 1.8s to 5s.
- Added ICE candidate error diagnostics and selected-route logging.
- Call UI now distinguishes TURN-unconfigured failures from ICE failures.
- `grcode.min.js` is not referenced anywhere in the Zento source; a browser-side 404 for that filename is not a Zento project asset.
