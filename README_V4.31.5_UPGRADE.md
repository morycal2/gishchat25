# Zento v4.31.5

- حساب سیستمی `admin` به نام «اطلاع‌رسانی» نمایش داده می‌شود و برای پیام/تماس/کنفرانس از سمت کاربران محافظت شده است.
- ارسال اطلاع‌رسانی همگانی از پنل مدیریت سازنده با پنل اختصاصی اضافه شد.
- پیام‌های هشدار و محدودیت همچنان از حساب «اطلاع‌رسانی» برای کاربر ارسال می‌شوند.
- پاسخ WebRTC در وضعیت اشتباه دیگر دوباره `setRemoteDescription` نمی‌شود؛ پاسخ‌های دیررس/تکراری نادیده گرفته می‌شوند.
- ظاهر صفحه تماس حرفه‌ای‌تر و شیشه‌ای‌تر شد و وضعیت «تماس امن» اضافه شد.
- پنل‌های مدیریتی و دیالوگ‌های مدیریتی از UI اختصاصی Zento استفاده می‌کنند و به `prompt/confirm/alert` مرورگر متکی نیستند.
